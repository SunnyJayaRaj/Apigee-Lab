# Security Policy

## Supported Versions

All projects in this repository are lab/educational implementations.
Only the latest revision on `main` receives fixes.

## Reporting a Vulnerability

If you find a security issue (exposed credentials pattern, policy bypass,
injection via unvalidated flow variables, etc.):

1. **Do NOT open a public issue.**
2. Email **SunnyJayaRajuKummu@gmail.com** with:
   - Description of the vulnerability
   - Steps to reproduce
   - Affected project/folder

You will get a response within 7 days.

## Scope Notes

- Bundles here are reference implementations — do not deploy them to
  production orgs without review.
- No live Apigee organization or cloud project is connected to this repo,
  so there are no runtime attack surfaces hosted from these sources.
